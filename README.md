# Personal Blog Website

This is my personal blog website where I share my thoughts, projects, and experiences. Built with React, TypeScript, and Vite.

## About

A modern, minimalist blog featuring:
- 📝 Blog posts with markdown support
- 🎨 Dark/Light theme toggle
- 🔍 Search functionality
- 🏷️ Tag-based categorization
- 📱 Responsive design
